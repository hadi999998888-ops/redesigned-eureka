# Gaming Hub & Loadout Dashboard

Готовый шаблон игрового веб-портала. Содержит структуру файлов для создания сайта с современной стилизацией (Dark/Cyberpunk UI).

## Структура проекта:
- `index.html` — главная страница
- `css/style.css` — стили оформления
- `js/script.js` — скрипты взаимодействия
- `assets/logo.svg` — векторный логотип

## Как использовать:
Распакуйте архив и откройте файл `index.html` в любом браузере.
